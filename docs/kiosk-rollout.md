# Classroom progress screen

Apply `supabase/migrations/20261002151518_classroom_kiosk.sql` before deploying. This adds one private capability-link table and read-only progress RPC. No roster, assignments, progress, or historical data are rewritten. Applied to Supabase project `awjwofukvfuvgjwsbqhe` on 2026-10-02; the remote migration ledger records version `20261002154844` (`classroom_kiosk`). The repository filename retains its original CLI timestamp. Do not reapply this migration.

Open `/teacher/settings/kiosk` (linked as **Pantalla de progreso** in teacher settings). Create and copy the link, then open it on the TV browser or tablet. The path is `/kiosk#<secret>`; `/dashboard#<secret>` is an alias. Both need the private fragment. The bare URL explains where to get the link. Only the hash of the 256-bit secret is stored, so the original link is shown once and should be bookmarked. Replacing/disabling the link revokes access on the next refresh.

All active students are shown alphabetically, including those without enabled zones. The snapshot uses today's school date in America/Santo_Domingo. Only names, daily goal/publication state, and enabled-zone identifiers/status are exposed. There are no emails, student IDs, assignment titles/URLs, comments, journal contents, or mutation controls. The kiosk capability is independent of PE and cannot confirm participation or change progress. Anyone with the link can view these names and statuses; use the screen within the school.

Completed zones are green, pending reviews yellow, and the rest neutral. Actual completion respects configured completion methods; recorded time alone does not complete teacher-confirmed work. Pending zones do not count as approved completion. Progress refreshes every 30 seconds. TV pages rotate every 15 seconds; previous/next, pause, show-all, refresh, and fullscreen controls are available. Tablets can choose **Ver todos** and scroll. Connection failures visibly retain the last successful snapshot, while revoked links clear it. Midnight switches automatically on refresh. No service-role key or new hosting provider is required.
